# Little Words

Một MVP web game học tiếng Anh cho trẻ em. Ứng dụng chạy tĩnh trên trình duyệt, không cần tài khoản hay máy chủ backend.

## Chạy thử trên máy

Từ thư mục dự án, chạy:

```sh
python -m http.server 8000
```

Mở `http://localhost:8000` trong trình duyệt. Có thể dùng `npm test` để chạy kiểm thử logic và giao diện cơ bản.

Game dùng giọng đọc tiếng Anh có sẵn trong trình duyệt và lưu điểm cao, từ đã gặp cùng tùy chọn âm thanh trong `localStorage` của thiết bị.
